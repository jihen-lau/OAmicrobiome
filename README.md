# Orang Asli Microbiome
This study investigates the gut microbiome diversities, predicted pathways and resistomes of three indigenous OA, Jahai, Temiar, and Temuan communities with different lifestyles and degree of urbanisation. We included an urban Malay group as comparison. 

## How to read my codes
Covariates used is library size to correct for uneven sequencing without using rarefaction.

Mia.Rmd holds the bulk of the microbiome anlaysis, namely alpha, beta, linear models, predicted pathway analysis and figures.

AMR script has the preprocessing of ARG load and mapping to ResFinder v4.0

Resistome_code.qmd has all the codes for the resistome analysis, including alpha, beta diversity, and ARG differential abundance analysis using MaAslin3.
